# UTM Desk NoSQL Cloud

Proyecto Unidad II · Bases de Datos en la Nube · UTM. Sistema de gestión, resolución y analítica de incidencias del campus sobre MongoDB Atlas.

## Qué hay en esta carpeta
| Ruta | Contenido |
|---|---|
| `AGENTS.md` · `CLAUDE.md` · `MEMORY.md` | Instrucciones y memoria del proyecto para Claude Code |
| `PROMPT-INICIAL.md` | Prompt para arrancar la implementación |
| `docs/` | Enunciado, constitución y (después) capturas y documentos |
| `specs/001-utm-desk/` | Spec (qué), plan (cómo) y tareas |
| `server/` · `web/` | API Express y UI React (aún vacíos) |
| `postman/` · `entregables/` | Colección Postman, script maestro y JSON exportado |

## Cómo arrancar
1. Revisar y aprobar `spec.md`, `plan.md` y `tasks.md`.
2. Abrir una terminal aquí, ejecutar `claude` y pegar `PROMPT-INICIAL.md`.
3. Hacer T00 (cuentas) con ayuda de Claude Code.
